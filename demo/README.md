# WebSocket2Serial 全功能演示页

独立、零构建的单文件演示页：`websocket2serial-demo.html`。  
覆盖 7 个管理动作、5 个事件、数据 WebSocket、多会话、调试订阅/回放、管理页开关、错误码/close code、宽限重连，以及双端口回环自检。

## 与功能测试页的关系

- 功能测试页 `http://127.0.0.1:8766/test` 是同一套功能的浅色独立页面：自动读取管理端口，不提供手动连接、打开管理页或管理页开关；一键演示会跳过「关闭管理页」步骤。
- 管理页 `/` 提供状态监控与帮助，并用新标签打开功能测试页和串口助手；本文件是独立深色版，通过本地静态服务打开，保留管理端口输入、打开/切换管理页，以及一键演示中的管理页开关。
- 两份代码并存，功能变更必须同时修改 `demo/websocket2serial-demo.html` 与 `src/assets/js/demo.js`，并分别冒烟。

## 启动

1. 启动桥接工具（默认管理 WS `127.0.0.1:8765`、管理页 `127.0.0.1:8766`）：

   ```powershell
   cd D:\projects\webSocket2Serial
   cargo run
   ```

   或直接运行已打包的 `websocket2serial.exe`。

2. 在项目根目录启动本地静态服务：

   ```powershell
   python -m http.server 8080 --bind 127.0.0.1
   ```

3. 打开：

   ```
   http://127.0.0.1:8080/demo/websocket2serial-demo.html
   ```

不要用 `file://` 直接打开：浏览器会发送 `Origin: null`，桥接默认拒绝。  
如果改了桥接配置的管理端口，在页面顶部输入实际端口再点“连接”。

## 用法

- **端口页**：查看 `ports.list` 与热插拔 `ports.changed`，可把某个端口设为 A/B。
- **会话页**：选择 A/B 串口，设置波特率/数据位/校验/停止位/流控/DTR/RTS，打开或关闭会话。参数不写死，任何串口环境都可以选。
- **双端口终端**：A/B 各自一个数据 WS；文本/HEX 发送，HEX/ASCII 或时间戳显示，暂停/清空/导出，宽限重连，模拟异常断开（3001），正常 1000 关闭。
- **调试**：订阅全部或指定会话的 `debug.frame`（可 replay），显示 seq 和缺口；`session.write` 调试写；导出缓冲。
- **边界自检**：第二数据客户端 4002、重复 open PORT_BUSY、错误 token、缺失端口 PORT_NOT_FOUND、非 active 写 SESSION_STATE、未知 action、文本帧 1003、超大帧 1009、异常断开 grace、正常关闭。
- **一键完整演示**：自动选择两个不同串口（优先使用输入框里指定的，否则取列表前两个），依次跑连接、端口、打开、双向 4KB 回环、计数、调试、错误码、正常关闭/重开、宽限重连、管理页开关和清理。A/B 必须是互连的一对串口；若不是，数据回环步骤会明确提示，不会误报为协议失败。

## 环境适配

- **不硬编码任何 `COM*` / `/dev/tty*`**：端口列表来自 `ports.list`，A/B 可手输或用下拉；一键演示自动从当前系统取两个不同端口。
- 换到另一台机器时，只要桥接在运行、页面通过 `http://127.0.0.1:<port>` 打开，选择该机器上的两个互连串口即可。
- 页面 Origin 必须在默认白名单 `http://127.0.0.1:*` / `http://localhost:*` 内；用 `127.0.0.1` 或 `localhost` 打开。
- 页面不依赖 CDN、字体或网络；兼容 Chrome 109 / Firefox 115 ESR。

## 限制

- 托盘和开机自启只能从 `hello` / `/api/config` 读取状态，网页不能控制；修改请用托盘菜单。
- 浏览器不暴露 WebSocket 握手的 HTTP 404：错误 token 会显示为握手失败/close 1006。
- 浏览器 WebSocket API 只允许关闭码 `1000` 或 `3000-4999`，发 `1001` 会抛 `InvalidAccessError`；因此“模拟异常断开”使用 `3001`，服务端对非 1000 关闭统一进入 grace。
- 数据 WS 的动态端口若落在浏览器禁用端口（如 5060），演示页会自动关闭该会话并重开换端口；事件日志会给出提示。
- 一键演示使用 4KB 小块。虚拟串口对在 64KB 全双工突发下可能丢字节，长稳/921600 必须用真实 USB 串口验证。
- 演示页会关闭 A/B 会话（包括你手动打开的同槽会话）再开始一键演示；不会动其他第三方会话。
- 关闭管理页（`admin.set false`）只影响 8766 的 HTTP 管理页，不影响本演示页与管理 WS；一键演示结束会恢复开启。
