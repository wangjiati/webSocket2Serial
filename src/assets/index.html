    快速开始

    1. 在「端口」子 tab 确认当前机器的串口
    2. 在「会话」子 tab 选择参数并打开 A/B
    3. 在「双端口终端」验证双向收发
    4. 若 A/B 是互连的一对串口，点击「开始完整演示」

    功能演示覆盖

    管理动作：ports.list / session.open / session.close / session.list / session.write / debug.subscribe（admin.set 在概览页）
    事件：hello / ports.changed / session.state / debug.frame / admin.state
    数据面：二进制、文本/HEX、close code、grace、lastGap
    边界：4002 / PORT_BUSY / PORT_NOT_FOUND / SESSION_STATE / UNKNOWN_ACTION / 1003 / 1009

    注意

    托盘/开机自启只能读取状态，不能从网页控制。
    浏览器不暴露握手 HTTP 404，错误 token 会显示为握手失败/close 1006。
    浏览器不能发送 close 1001；异常断开用 3001 模拟，服务端统一进入 grace。
    本页由桥接工具内嵌提供，管理端口自动读取，无需手动连接。
    虚拟串口对在大块全双工下可能丢字节；一键演示使用 4KB 小块。
